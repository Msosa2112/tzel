# debug_legacy

Scripts Python de depuración puntual (scraping de Clark/Floyd/JCCO, pruebas de Turso/Telegram/Spark)
movidos desde la raíz del proyecto. No forman parte del pipeline ni del servidor.

Se ejecutan desde la raíz del repo para conservar las rutas relativas:

```powershell
python scripts/debug_legacy/<script>.py
```
